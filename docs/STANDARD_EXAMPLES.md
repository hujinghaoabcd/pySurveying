# Standard and regression examples

pySurveying separates **reference-backed numerical examples** from **transparent package regression examples**. This avoids calling a synthetic dataset a published standard.

## 1. Reference-backed parameter adjustment

The strongest current numerical references come from 宋力杰《测量平差程序设计》.

### Section 3.1.5 — independent weighted observations

The repository reproduces the printed six-equation parameter-adjustment example with observation weights:

```text
P = [1, 1, 2, 1, 2, 2]
```

Expected textbook result:

```text
X = [ 2, 1, -4 ]
V = [ 2, 4, -1, 2, -4, 5 ]
sigma0 = 6
```

Expected cofactor matrix:

```text
Qxx =
[[0.38888889, 0.27777778, 0.05555556],
 [0.27777778, 0.55555556, 0.11111111],
 [0.05555556, 0.11111111, 0.22222222]]
```

Automated regression: `tests/test_adjustment.py::test_song_lijie_parameter_adjustment_example`.

Runnable example: `examples/textbook_parameter_adjustment.py`.

### Section 3.2.5 — correlated observations

The second example uses the complete printed symmetric 6×6 observation weight matrix rather than a diagonal shortcut.

Expected textbook result:

```text
X = [ 2, 1, -4 ]
V = [ 2, 2, -5, 3, -6, 14 ]
sigma0 = 6
```

The printed `Qxx` is the same as in Section 3.1.5.

Automated regression: `tests/test_adjustment.py::test_song_lijie_correlated_parameter_adjustment_example`.

These two examples exercise both supported `least_squares(..., P=...)` paths: independent weights and a full correlated weight matrix.

## 2. Direction-observation convention cross-check

GNU Gama is used as an external semantic cross-check for direction observations. Its official manual states that directions belonging to one occupied station share an orientation-shift unknown, with the relationship between observed direction and bearing represented through that station orientation. pySurveying follows the same practical modeling idea by creating one orientation unknown for each station that contains `direction` observations.

Reference:

- GNU Gama manual, **Directions**: https://www.gnu.org/software/gama/manual/html_node/Directions.html
- GNU Gama local-network example: https://www.gnu.org/software/gama/manual/html_section/Example.html

This is currently a **model-convention cross-check**, not a claim that pySurveying reproduces the entire GNU Gama example network numerically. GNU Gama supports a wider set of coordinate-system, stochastic-model and network options.

## 3. Transparent package regression datasets

The following examples are intentionally small enough to inspect manually and are shipped in `examples/data/`.

### 3.1 Closed traverse

`traverse_angles.csv` contains four measured interior angles and four side lengths. The workflow:

1. closes the polygon angle sum to 360°,
2. propagates side azimuths,
3. computes raw coordinate increments,
4. distributes coordinate closure by Bowditch,
5. verifies that the adjusted final coordinate returns to the start point.

Automated regression: `tests/test_example_data.py::test_traverse_example_data_closes_after_adjustment`.

### 3.2 Unequal-weight leveling network

`leveling_fixed.csv` and `leveling_observations.csv` define one benchmark, two unknown heights and three height-difference observations with unequal standard deviations.

The example verifies that:

- the network has one degree of freedom,
- weights are formed from `1/sigma²`,
- adjusted heights remain close to the transparent nominal values,
- a posterior unit-weight standard deviation is available.

Automated regression: `tests/test_example_data.py::test_leveling_example_data_is_redundant_and_adjusts`.

### 3.3 Redundant 2D distance control network

`control_points.csv` and `control_observations.csv` define three fixed control points and one approximate unknown point. Three exact distances recover the unknown point at `(40, 30)` from the supplied approximation `(39, 31)`.

The example also exercises control-network covariance, redundancy, per-observation quality diagnostics and point precision summaries.

Automated regression: `tests/test_example_data.py::test_control_network_example_data_recovers_unknown_point`.

### 3.4 2D coordinate transformation

`common_points.csv` contains four common points generated by a known translation, scale and rotation. It is intended for the similarity/affine transformation examples and GUI.

## 4. Robust estimation and gross-error regression

The robust-estimation organization is checked against the same textbook's equivalent-weight and gross-error sections:

- Huber / IGG1 / IGG3 equivalent-weight functions,
- iteratively reweighted adjustment,
- standardized residual screening,
- repeated removal and re-adjustment.

The package tests deliberately contaminate distance and azimuth observations and verify that the largest gross observation can be localized by original observation index.

## 5. What is not yet claimed

The project does **not** currently claim certified equivalence with commercial surveying software, national control-survey regulations, or every GNU Gama/JAG3D stochastic-model option. Instrument readers are also not manufacturer-certified parsers.

For legal, cadastral, metrology or high-order production work, independently verify units, datum definitions, observation conventions, stochastic models and acceptance tolerances against the governing specification.
